모으는 정보

이 도구는 회원 가입이 없고, 운영자 서버로 어떤 개인정보도 보내지 않습니다.

브라우저에 저장하는 것

  • 회원이 넣은 YouTube API 키, 고른 조건, 오늘 쓴 점수 추정치를 그 브라우저의 저장소(localStorage)에만 둡니다.
  • API 키는 유튜브 서버(www.googleapis.com)에 검색을 요청할 때만 쓰입니다.
  • 브라우저의 사이트 데이터를 지우거나 열쇠 칸을 비우고 「저장」을 누르면 삭제됩니다.

YouTube API 서비스

영상과 채널의 공개 정보는 YouTube API 서비스로 가져옵니다. 이 도구를 쓰면 YouTube 서비스 약관에 동의하는 것으로 봅니다. Google의 정보 처리는 Google 개인정보처리방침을 따릅니다. API 키 접근 권한은 Google 보안 설정 또는 구글 클라우드 콘솔에서 삭제할 수 있습니다.
