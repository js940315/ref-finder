레퍼런스 발굴기

구독자는 적은데 조회수가 터진 영상을 찾아 내 쇼츠 기획으로 바꿉니다.

이 목록은 하루 한 번 미리 뽑아 둔 것이라 내 점수를 쓰지 않습니다.

열쇠는 이 브라우저에만 저장되고 유튜브 말고는 어디에도 보내지 않습니다. 받는 방법은 「사용법」 탭에 있습니다.

이렇게 고릅니다

  • 구독 대비 = 조회수 ÷ 구독자 수. 구독자 1만 명 채널에서 50만 회가 나오면 50배입니다. 구독자 덕이 아니라 영상 자체가 퍼졌다는 뜻입니다.
  • 평소 대비 = 이 영상 조회수 ÷ 그 채널 최근 20편 조회수의 가운데 값. 그 채널에서도 유독 터진 영상인지 봅니다.
  • 구독자를 숨긴 채널은 구독 대비를 셀 수 없어 기본으로 뺍니다(필터에서 켤 수 있음).
  • 유튜브가 구독자 수를 반올림해서 알려 주므로 배수는 대략치입니다.

무료 열쇠(API 키) 받기 — 5분

  1. 구글 클라우드 콘솔에 구글 계정으로 들어가 새 프로젝트를 만듭니다(이름 아무거나). 결제 정보는 넣지 않아도 됩니다.
  2. YouTube Data API v3 화면에서 「사용」을 누릅니다.
  3. 사용자 인증 정보 → 「사용자 인증 정보 만들기」 → 「API 키」를 누르면 열쇠가 나옵니다.
  4. 안전을 위해 열쇠 옆 「키 수정」에서
    • 「API 제한사항」 → 「키 제한」 → YouTube Data API v3 만 고릅니다.
    • 「애플리케이션 제한사항」 → 「웹사이트」 → 이 페이지 주소()를 넣습니다.
  5. 열쇠를 복사해 「키워드로 찾기」 탭에 붙여 넣고 저장합니다.

하루 한도

열쇠 하나에 하루 10,000점이 무료입니다. 검색 한 번(50개)이 약 100점이라 하루 약 90번 찾을 수 있습니다. 한국시간 오후 4~5시쯤 다시 채워집니다. 돈이 나가는 일은 없습니다.

쇼츠로 바꿀 때 지킬 것

  • 찾은 영상은 구성을 배우는 참고용입니다. 내려받아 다시 올리면 저작권 신고와 채널 정지를 받을 수 있습니다.
  • 「쇼츠 기획 메모 복사」를 눌러 첫 2초·반전·결말을 직접 보고 적은 뒤, 내가 찍었거나 쓸 권리가 있는 원본으로 만드세요.
  • 제목만 보고 짐작하지 말고 영상을 끝까지 보고 적으세요.
